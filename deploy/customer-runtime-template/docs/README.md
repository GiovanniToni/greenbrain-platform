# GreenBrain Customer Runtime Template

## Obiettivo
Installazione locale presso il cliente con:
- database locale
- backend locale
- ML locale
- dati locali

## Accesso
Gli utenti entrano da greenbrain.it con login centrale.

## Modalità target
Il runtime locale sincronizza dati selezionati verso il cloud, così il frontend online può mostrare dati aggiornati.

## Passi futuri
- docker compose locale cliente
- script installazione
- sync agent locale -> cloud
- healthcheck e monitoraggio
