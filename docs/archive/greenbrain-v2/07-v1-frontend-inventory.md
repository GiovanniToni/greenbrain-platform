# GreenBrain V1 Frontend Inventory

## Core pages for V1

### 1. System status page
Purpose:
- verify backend/db/frontend connectivity
- verify local runtime status

Data needed:
- system info
- db info
- pipeline status

### 2. Forecast overview
Purpose:
- show forecast summary
- show date range
- show number of families
- show number of price bands

Data needed:
- forecast summary
- forecast sample

### 3. Family explorer
Purpose:
- browse family list
- inspect one family forecast
- inspect one family price bands

Data needed:
- family list
- family detail
- family forecast timeseries

### 4. Sales overview
Purpose:
- show sales KPIs
- show main trends
- support dashboard replacement

Data needed:
- sales summary
- sales timeseries
- family ranking

### 5. Planner overview
Purpose:
- show planning outputs
- weekly / assortment / density

Data needed:
- planner endpoints

## Rule
V1 frontend should be simple and operational first, polished later.
