# Customer Handoff Checklist

## Prima della consegna
- release ufficiale buildata
- tag git creato
- package smoke test eseguito
- runbook installazione aggiornato
- checklist segreti aggiornata

## Durante installazione
- runtime locale estratto
- env locale compilato
- tunnel configurato
- tenant registrato centralmente
- compose validato
- runtime avviato

## Dopo installazione
- health backend OK
- frontend locale OK
- accesso remoto OK
- tenant routing OK
- sync agent configurato se previsto
- backup iniziale eseguito

## Fase assistita GreenBrain
- collegamento DB sorgente cliente
- mapping dati grezzi
- ETL iniziale
- verifica primi dataset
