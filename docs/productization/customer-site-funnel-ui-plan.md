# Customer Site Funnel UI Plan

## Obiettivo
Trasformare il sito GreenBrain attuale in funnel coerente per:
- scoperta prodotto
- scelta piano
- signup
- login
- area cliente
- attivazione abbonamento
- download bundle
- istruzioni installazione

## Principi UI
- mantenere design system e stile esistenti
- non stravolgere landing e layout
- riusare componenti attuali
- rendere il funnel più chiaro e lineare
