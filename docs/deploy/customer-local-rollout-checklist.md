# Customer Local Rollout Checklist

## Pre-install
- tenant_code definito
- hostname tenant definito
- credenziali cliente definite
- macchina cliente verificata
- docker installato
- accesso db sorgente verificato

## Install locale
- env compilato
- db locale creato
- backend locale avviato
- frontend locale avviato
- ML locale predisposto
- launcher desktop creato

## Auth centrale
- tenant registrato in greenbrain_tenants
- runtime registrato in greenbrain_runtime_connections
- utente cliente registrato
- home_host coerente
- test login centrale ok

## Accesso remoto
- tunnel configurato
- tunnel healthcheck ok
- test accesso remoto ok
- revoca accesso testata
