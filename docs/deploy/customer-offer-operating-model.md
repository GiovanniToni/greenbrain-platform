# Customer Offer Operating Model

## Prodotto base
Il cliente acquista GreenBrain installato in locale con:
- db locale
- backend locale
- frontend locale
- ML locale
- dati locali
- launcher desktop

## Uso locale
Il cliente apre GreenBrain dal proprio PC tramite launcher desktop.

## Opzione premium
Accesso remoto da qualunque luogo tramite:
- login centrale su www.greenbrain.it
- account personale
- instradamento tenant
- tunnel sicuro verso runtime locale cliente

## Principio dati
I dati del cliente restano nel suo ambiente locale.
GreenBrain non usa come standard un cloud proprio per archiviare i dati del cliente.

## Benefici commerciali
- maggiore fiducia lato privacy
- installazione proprietaria del cliente
- upsell naturale per accesso remoto premium
