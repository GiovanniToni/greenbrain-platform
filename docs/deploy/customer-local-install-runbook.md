# Customer Local Install Runbook

## Obiettivo
Installare GreenBrain presso il cliente con:
- db locale
- backend locale
- frontend locale
- ML locale
- accesso desktop locale

## Passi
1. compilare env cliente
2. avviare docker compose locale
3. verificare frontend locale
4. verificare backend locale
5. creare launcher desktop
6. registrare tenant centrale in modalità local-runtime
7. configurare tunnel sicuro
8. testare accesso remoto

## Nota
Il cloud GreenBrain non è il repository standard dei dati cliente.
